# Notices

## Sample PDFs

`src/pdf_redpen/data/sample_report.pdf` and `examples/sample_embedded.pdf` contain text
written for this repository (fictional report sentences, no real company or person).
`sample_report.pdf` only references a CJK font by name and embeds no font file.
`examples/sample_embedded.pdf` embeds a subset of "Droid Sans Fallback Regular", the font
bundled with PyMuPDF (https://pymupdf.readthedocs.io/en/latest/font.html, checked 2026-11-09),
which is an Android distribution font under the Apache License 2.0.
Both files are generated by `scripts/make_sample_pdf.py`.

## Dependencies

| Package | Version | License |

| pdfplumber | 0.11.10 | MIT |

PyMuPDF (AGPL-3.0) is **not** a dependency. It is only needed to regenerate the sample PDFs
with `scripts/make_sample_pdf.py`, a development script that the package never imports.
